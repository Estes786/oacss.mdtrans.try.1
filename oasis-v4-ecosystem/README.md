## 🚀 DEPLOYMENT (MOBILE-FIRST, NO CLI REQUIRED)

### Quick Start Guide (Via Mobile Browser)

#### 1. Frontend Deployment (Vercel)
1. Open GitHub.com → Create new repository → Upload `front-oasis` folder
2. Open Vercel.com → "Import Project" → Connect GitHub → Select repository
3. Deploy settings: Framework = Next.js, Build command = `npm run build`
4. Click "Deploy" → Get production URL

#### 2. Backend Setup (Supabase)
1. Open Supabase.com → Create new project
2. Go to "SQL Editor" → Paste SQL from `database-oasis/migrations/`
3. Go to "Edge Functions" → Create new function → Paste code from `back-oasis/functions/`
4. Go to "Settings" → Copy API keys → Add to Vercel environment variables

#### 3. AI/ML Setup (HuggingFace)
1. Open HuggingFace.co → Create new Space
2. Upload files from `hf-oasis/` folder
3. Set Space to "Gradio" or "Streamlit" SDK
4. Get Space URL → Add to backend environment variables

#### 4. Payment Integration (DOKU)
1. Register at DOKU.com → Get API credentials
2. Add to Supabase Edge Functions environment variables
3. Test payment flow from frontend

### Environment Variables
```env
# Frontend (.env.local)
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
NEXT_PUBLIC_HF_API_URL=your_huggingface_space_url

# Backend (Supabase Edge Functions)
SUPABASE_SERVICE_KEY=your_service_key
DOKU_CLIENT_ID=your_doku_client_id
DOKU_SECRET_KEY=your_doku_secret_key
HF_API_TOKEN=your_huggingface_token
```
